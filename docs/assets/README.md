# README visuals

The three GIFs are deliberately selected public examples made from the repository's synthetic source fixture. They are not derived from user-uploaded reference videos. See [the reconstruction example](../../examples/reconstruction-demo/README.md) for provenance, reproducible commands, edit steps and verification limits.

| Asset | Left | Right |
| --- | --- | --- |
| `conversion.gif` | Independently drawn source video | Actual automatic HTML/SVG reconstruction |
| `title-edit.gif` | Unedited reconstruction | Same project with the title edited in the app |
| `color-edit.gif` | Unedited reconstruction | Same project with two shape fills edited in the app |

All GIFs are silent 3-second loops, 60 frames at 20 FPS, 960 × 328 including labels. The headers explain the comparison and are not part of the reconstructed scene. See [the manifest](showcase-manifest.json) for hashes and sizes.

`editor.png` is a separate screenshot of the [authored editable-motion example](../../examples/editable-motion/README.md). It shows the editor interface, not an automatic conversion result.
