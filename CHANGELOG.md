# Changelog

## 0.1.0 — 2026-10-25

Initial public source release as **Saegim (새김)**.

- Local video analysis, editable HTML/SVG projects and standalone export.
- Text editing, gradients, layer stacking, cuts and frame-by-frame redraw.
- Element export and source-versus-render comparison workflows.
- Repository skills for reconstruction and iterative part matching.
- Synthetic examples, engine/backend/browser checks and public-source packaging.

The project is experimental. Semantic part extraction and hidden-surface reconstruction still require input-specific annotations and review. Internal `FRAMEFORM_*` environment variables and existing project/storage identifiers are retained for compatibility.
